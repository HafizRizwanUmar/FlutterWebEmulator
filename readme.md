Run and test Flutter web apps in a phone-like Flutter Web Emulator directly inside VS Code.

## 🚀 Overview

**Flutter Web Emulator** is a powerful VS Code extension designed to streamline Flutter web development. It provides a mobile-like environment within your IDE, allowing you to preview your apps on various device presets without leaving your workspace. 

This project is now **100% free and fully open-source**! All premium features (including ADB mirroring and screenshot capture) are unlocked for everyone.

## ✨ Key Features

- **📱 Multiple Device Presets**: Choose from popular devices like iPhone 14, Pixel 7, iPad Air, and more.
- **🔄 Hot Reload Support**: Instantly reflect your code changes in the Flutter Web Emulator.
- **↩️ Device Rotation**: Test your app's responsiveness in both portrait and landscape modes.
- **🤳 Android Mirroring (ADB)**: Mirror your real Android device screen directly into VS Code.
- **📸 Screenshot Capture**: Easily take screenshots of your app for documentation or testing.
- **🛠️ Custom ADB Path**: Use the bundled ADB or specify your own.
- **⚡ Auto-Reload**: Enable automatic reloading on Dart file save.

## 🛠️ Getting Started

1.  **Install the extension** from the VS Code Marketplace.
2.  **Open a Flutter project** in VS Code.
3.  **Start the Flutter Web Emulator** using the play icon in the editor title bar or by running the command `Flutter Web Emulator: Start`.
4.  **Save your Dart files** to see changes instantly (if Auto-Reload is enabled).

## ⌨️ Shortcuts

-   `Ctrl+R` (Windows/Linux) / `Cmd+R` (macOS): **Reload Flutter Web Emulator**
-   `Ctrl+Shift+R` (Windows/Linux) / `Cmd+Shift+R` (macOS): **Rotate Device**
